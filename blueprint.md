- **Stack**: Ultra-Light Vanilla JS + Serverless Intelligence
- **Architecture**: Edge-First Decoupled Architecture (Cloudflare Pages)
- **Primary Objective**: Global Freelance Income Transparency

## 2. Infrastructure Directive

### 📁 Folder Structure
- `/public`: Static Assets (HTML, CSS, JS, Images, Legal Docs)
- `/functions`: Serverless Backend (JavaScript Workers)
  - `functions/api/chat.js`: AI Oracle Interface
- `/skills`: AI Agent Operating Protocols

### ⚙️ Core Logic
1. **Income Engine (Precision Calculation)**:
   - Vanilla JS based tax logic for KR, US, JP, CN, TW, UK, CA, DE.
   - Real-time Chart.js visualization for financial decision making.
2. **AI Oracle (Gemini 2.5 Flash)**:
   - Serverless functions proxying requests to Gemini API.
   - Intelligent hourly rate advisory based on multi-dimensional input.
3. **Deployment (CI/CD)**:
   - Wrangler-CLI driven deployment to Cloudflare Edge.
   - Secure environment variable management via Pages Secrets.

## 3. Security Protocol
- **Edge Routing**: All API calls are non-transparent through Cloudflare Workers.
- **Secret Management**: No API keys in client-side code; strictly server-side environment variables.
- **Privacy Compliance**: GDPR and Korean PIPA ready through dedicated legal endpoints.
